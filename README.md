# MIC Lab Website (preview)

Website of the Mobile and Intelligent Computing Laboratory (MIC Lab), San Francisco State University, directed by Dr. Zhuwei Qin.

Preview: https://zhuweiqin.github.io/mic-lab-website/

- Publications: edit `_data/sources.yaml` (the site reads the generated `_data/citations.yaml`).
- Projects: `_data/projects.yaml`
- Team: `_members/*.md` (alumni list is in `team/index.md`)
- News: one file per item in `_posts/`

_Built with [Lab Website Template](https://greene-lab.gitbook.io/lab-website-template-docs)_
